[프로젝트 개요]
핵 불안정화기 Core Destabiliser를 사용한 Soul Core 플리핑의 평균적인 수익을 계산하는 프로젝트
1. Core Destabiliser 적용이 가능한 poe.ninja 최근 시세 기준 가장 저렴한 Soul Core에 Core Destabiliser를 사용했을 때 얻어지는 평균적인 수익을 계산
2. to do that, Core Destabiliser를 사용했을 때 Soul Core, Endgame Soul Core, Ancient Soul Core, 그리고 적용한 soul core가 파괴되는 분포를 확인해야 하며, 이것은 사용자가 확인해줄 것.

[Mechanics]
Using this item can result in the following outcomes:
   - Double the Soul Core
   - Transform the Soul Core into another random Soul Core of the same tier
   - Transform the Soul Core into an ancient soul core
   - Destroy the Soul Core
