이렇게 한글이나 영문 PoE2 장비 아이템 정보가 주어졌을 때, 다른 python 스크립트에서 PoE2 API에 쿼리 요청을 보낼 때 필요한 장비 정보를 읽어올 json 데이터 파일에 내가 원하는 기준으로 정보를 정리해서 저장하는 python 스크립트(parser)를 작성해.

Here are few rules:
- fractured 라도 fractured = any 로 검색
- desacrated 라도 desacrated = any로 검색
- socket 개수는 exact 검색
- 대부분의 데이터를 가능하면 exact 검색
- mirrored 상태 저장. 동일하게 사용.
- corrupted 상태 저장. 동일하게 사용.

- dps와 같이 장비 자체가 갖지 않는 2차적 정보. 장비 자체의 정보만 저장
- 랜덤 생성 아이템 이름
- augment(Rune, etc) 정
- 모드의 roll 값, value 수치 모두. 아이템 모드는 종류, 티어만 저장.

저장하지만 아마 쓰이지 않을 값:
- 아이템 이름과 요구사항 사이의 모든 정보(퀄리티, 물리 피해, 원소 피해, 치명타 명중 확률, 초당 공격 횟수 등)
- 예외적으로 무기나 방어구의 퀄리티가 30%, 장신구가 일 경우
- fractured 분열 모드 정보는 저장은 하지만 쿼리에서 사용하지 않을 것. Fractured 된 옵션은 그냥 그 옵션으로 검색. (fracutred 힘 +1이 아닌 힘+1로 검색)


새로운 서비스를 제작할거야.

A. 서비스의 목적: 서비스가 제작 단가를 계산 가능한 어떤 PoE2 장비 specification이 데이터로 주어졌을 때, 그 장비의 적정 시장가를 PoE2 API에서 검색하고(이 부분은 이미 만들어진 다른 서비스인 overquality-flip을 참고할 것), 이를 통해 예상 마진을 계산, 사용자가 목록에 있는 장비를 제작하여 판매(장사)하는 것이 좋을지 판단하는데 도움이 되는 데이터를 계산하고 제공하는 것.
B. 제작 단가의 계산: 서비스가 제작 단가를 계산하는 방식은, 클로드 세션에서 1. 목표 장비의 정보(can be an image, or copy past information from the client or pob)를 받아서 python 쿼리가 가능한 형태로 저장, 2. 사용자와 대화를 통해 해당 장비를 제작하는 최적의 방법을 학습, 제작 방식을 파일에 기록. 4. 제작에 들어가는 총 평균 비용을 확률적으로 계산, (A)에서 마진을 예상하는 비용으로 사용.
